Use this prompt only when `docs/implementation/STATUS.md` selects a Phase 4 task and Phases 1–3
are recorded green. Otherwise stop and follow the selected task's plan.

Read `AGENTS.md`, `docs/implementation/QUALITY_LOOP.md`, `STATUS.md`, the complete selected task,
and the evaluation, risk, definition-of-done, operations, and release contracts. Run repository
verification, freeze one task brief, and follow the repository-owned TDD, fan-out, independent
review, retry, Git, status, and reporting gates.

unverified LLM output. Report denominators and failures; measure planner, evidence, latency,
resilience, and ablation claims. Do not claim release readiness before the task's clean-room,
provenance, compliance, and freeze gates have current evidence. End after the selected task.
