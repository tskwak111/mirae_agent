# 주최측 평가 운영기간 및 헬스체크 공지

출처: 프로젝트 소유자가 2026-09-06 대화에 전달한 주최측 공지 원문.
게시물 원본 URL은 제공되지 않았다. 아래 운영기간은 이전 과제 PDF의 기간보다
나중에 전달된 공식 안내로 적용한다. 헬스체크 응답의 notice_version은 2026-09-04다.

## 평가 서버 운영시간

평가를 위한 서버 운영 시간을 안내 드립니다. 아래 기간 동안 순차적으로
참가팀 답변 수집이 진행될 수 있습니다.

- 서버 운영기간: 09.07(월) 10:00 - 09.11(금) 15:00
- 제출 기한: 09.06(일) 23:59

위 제출 기한 내 깃헙을 통해 과제 제출(push)을 완료해주시기 바랍니다.
제출 기한이 지난 뒤, 제출 결과를 수정하는 행위는 엄격히 금지되며
제출해주신 코드를 검증하는 작업도 평가 과정에서 진행될 수 있습니다.

## 금융상품(product) 주최측 헬스체크

9월 7일부터 실제 답변을 수집할 서버에 헬스체크를 열어두었습니다.
공개망 통신에 문제가 없는지 평가 시작 전에 스스로 확인하실 수 있습니다.
헬스체크는 실제 평가와 무관하며 수행 여부는 평가점수에 반영되지 않습니다.

참가팀 서버 안에서, 실제 API가 돌아가는 장비에서 실행합니다.

```sh
curl -s http://34.47.123.221/health
```

정상 응답 예시:

```json
{"status":"ok","server_time":"2026-09-07T10:00:00+09:00","notice_version":"2026-09-04"}
```

`status: ok`는 참가팀 서버 → 주최측 방향 공개망 통신이 정상임을 뜻합니다.
연결 실패 시 아웃바운드 방화벽·프록시를 확인합니다. server_time은 주최측
서버 현재 시각(KST)이며 참가팀 서버 시계와 크게 다르면 NTP를 확인합니다.

- 헬스체크는 HTTP(80)만 제공합니다. 실제 답변 수집은 HTTP, HTTPS 모두 허용합니다.
- 실제 답변 호출의 주최측 발신 IP와 헬스체크 IP: `34.47.123.221`.
- 주최측 발신 IP만 허용하는 팀은 해당 IP를 허용해야 합니다(터널 사용 팀 제외).
- 호출 내역(발신 IP·시각)은 주최측에 기록되며 평가 기간 장애 대응 참고 자료로만 사용됩니다.

## 프로젝트 관측 기록 (공식 공지와 구분)

2026-09-06 02:40:45 KST, 실제 API 장비 NCP 101.79.30.91에서 위 URL을 1회
호출했다. HTTP 성공, `status=ok`, `server_time=2026-09-06T02:40:45+09:00`,
`notice_version=2026-09-04`. 장비 시각은 같은 초였고 `NTPSynchronized=yes`,
`Timezone=Asia/Seoul`이었다. HCX 호출은 없었다.

이는 아웃바운드 관측이며, 주최측이 우리 `/answer`를 호출했다는 증거가 아니다.
방화벽, 제출 태그, 이미지, 서비스는 이 확인으로 변경하지 않았다.
